# 浮游 AQUARIUM · 虚拟角色社交观察池

本地优先的 React / TypeScript Web 应用。角色共享同一实体图谱，在不同世界中保留独立设定；规则引擎安排生活与社交机会，兼容 Chat Completions 的 AI 负责内容。内置五位原创角色的演示世界，演示消息始终带有标记。

## 运行

需要 Node.js 18.19+（推荐 22 LTS）与 npm。

```sh
npm ci
npm run dev
```

打开终端显示的 `http://127.0.0.1:5173`。第一次启动可选择配置 API 或先浏览演示。终端只用于开发；构建部署后，普通使用者在浏览器完成所有配置。

```sh
npm run build     # 类型检查、Vite 静态构建、生成带内容版本号的离线缓存
npm run preview   # 本地预览 dist
npm test          # 不消耗 API Token 的单元和集成测试
npx playwright install chromium
npm run test:e2e  # 浏览器测试；自动启动测试服务器
```

使用已有 Chromium 时可设置 `CHROMIUM_PATH=/absolute/path/to/chrome`。测试中的 API Key 是明确的测试字符串，网络响应来自本地拦截 fixture，没有真实模型调用。

## 静态部署

将 `npm run build` 生成的 **dist 全部内容** 放到 HTTPS 静态站点的根路径。也可通过 localhost 使用。使用根路径是当前 Vite / PWA 的部署约定；部署到子目录需要同时调整 Vite base、manifest、Service Worker 路径。不要通过 `file://` 打开。

应用不需要常驻服务器。关闭后不会运行；重新打开时从已保存的模拟时间补全。模型 API 仍需网络。生产版首次成功加载后可以离线浏览/编辑数据，真实生成要等恢复网络。

提供商必须允许浏览器 CORS 及 Authorization。无法直连时，应用会明确提示；不内置公共代理，也不要求普通用户自行运行代理服务。使用已有可信本地模型/代理时可填写其地址。此版没有捆绑桌面代理程序。

数据属于当前浏览器的当前源（协议、域名、端口）；更换域名/浏览器/设备需先导出再导入。密钥默认仅在内存，选择持久保存时以可读取形式存于 IndexedDB。备份不包含 API 密钥。
