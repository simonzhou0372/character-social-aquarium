# 游戏化界面与动效说明

本轮界面重构保留了原有的世界、角色、聊天、线下观察、关系、事件、时间控制和本地持久化数据。视觉层可以在 **世界设置 → 外观与动效** 中切换：

- **游戏界面**：默认版本，世界 HUD、舞台封面、角色档案卡、游戏式转场与事件演出。
- **经典界面**：重构前的观察池布局，用于快速回退；数据、当前世界与全部功能不变。

## 设计令牌

样式集中在 `src/styles.css` 的 `.game-ui` 作用域。主要令牌包括：

- 墨色结构层 `#111920`、纸色阅读层 `#fbf7ec`、酸性青柠 `#d9f36a`、珊瑚 `#ff7553`、水色 `#8ee8d4`。
- 世界代表色通过 `--world-color` 注入，背景封面通过 `--world-cover` 注入。
- 粗描边、低圆角、硬阴影用于操作和档案；聊天阅读区使用更高对比度与更克制的边框。
- 动效时长与曲线：按压 80–140ms，普通反馈 120–220ms，卡片 220–320ms，页面 420–600ms，重大演出 600–1500ms。

## 视觉层次

1. **环境层**：世界封面的低透明度背景、网格、漂移几何、昼/夜/黄昏色调。世界暂停时背景动画同步冻结。
2. **主界面层**：世界 HUD、游戏导航、角色舞台、聊天、场景、关系图、设置。
3. **互动反馈层**：按钮压缩、悬停位移、卡片选中、未读角标、数字变化、焦点轮廓。
4. **演出层**：页面扫入、世界切换、重大事件横幅、离线补全、场景演出阅读。

各层都通过 `pointer-events: none` 或局部容器管理，不会阻断模拟器或主要操作。页面切换与世界切换即使连续触发也不会留下遮罩：覆盖层使用一次性 CSS 动画，并在状态超时后卸载。

## 动效技术

- **CSS transitions / keyframes**：主要用于悬停、按压、背景漂移、扫描线、事件横幅和低开销状态反馈。
- **Web Animations API**：只用于读取和验证动画运行状态；没有为普通按钮创建独立 `requestAnimationFrame` 循环。
- **SVG**：关系图节点、连线、箭头、场景几何与环境装饰。
- **React 状态**：只负责触发进入/退出和选择，不把动画完成作为业务提交条件。

没有引入 PixiJS、GSAP 或 Motion 依赖。当前效果用 CSS/SVG 已经足够，减少多套动画系统争夺同一元素状态的风险。

## 页面与世界切换

- 普通导航使用短促的双层几何扫入，不覆盖主要操作，`pointer-events: none`。
- 世界切换使用带世界主题色的斜切面板与标题演出，约 1.15 秒；立即写入世界 ID，连续快速切换以最后一次为准。
- 页面内容使用 420ms 的轻量进入动画；关闭视觉效果时不播放。
- 角色资料使用共享的角色代表色与档案头图，不伪造不存在的属性。

## 聊天与阅读

- 新消息只做 260ms 的小幅进入动画；历史消息不会持续运行动画。
- 未读数量在变化时弹入；第一条未读保持静态轮廓提示，确保不依赖动画也能识别。
- 角色身份切换通过 `--role-accent` 同步输入框、标签和自身消息边界，历史消息的发送者不会被改写。
- 进入会话后默认仍使用可滚动历史；长列表保留原本的 100 条窗口与“加载更早的消息”。
- 线下观察新增可选的“演出阅读”模式，默认仍为完整、可搜索的档案阅读。演出的下一句、自动播放、速度和跳过都只改变阅读呈现。

## 事件与离线补全

- 重大事件横幅固定在 HUD 下方，非阻塞出现；事件原始内容已先行持久化，动画不参与保存结果。
- 事件详情按类型使用不同主题色；点击横幅的“查看事件”才打开完整档案。
- 离线补全界面显示真实阶段、真实事件/消息计数和实际时间进度。可“收进背景，继续运行”，不会取消任务。
- 关闭补全界面或刷新后，后台任务状态仍由现有任务队列与检查点恢复。

## 五档活跃度的模拟参数

下表是 `src/core/activity.ts` 实际提供给调度器的参数。旧三档没有修改；沸腾和狂欢额外允许在同一个调度段内开启多个互不冲突的会话。

| 参数                       | 热闹（旧） |  沸腾 |  狂欢 |
| -------------------------- | ---------: | ----: | ----: |
| 每小时机会槽 `onlineSlots` |          6 |     8 |    10 |
| 机会系数 `opportunity`     |       0.80 |  0.94 |  1.00 |
| 会话冷却（模拟分钟）       |          8 |     5 |     3 |
| 权重阈值                   |      0.055 | 0.044 | 0.033 |
| 话题间隔缩放               |       0.25 |  0.16 |  0.10 |
| 接续概率                   |       0.94 | 0.965 |  0.98 |
| 自然结束概率               |       0.09 | 0.065 | 0.045 |
| 私聊权重                   |       1.00 |  1.08 |  1.14 |
| 群聊权重                   |       1.15 |  1.32 |  1.55 |
| 每段最多独立开口           |          1 |     2 |     3 |
| 额外开口概率               |          0 |  0.22 |  0.30 |
| 大群偏好 `groupCrowdBonus` |          0 |  0.05 |  0.09 |
| 回复附加延迟（模拟分钟）   |          0 |   0.8 |   0.4 |

`groupCrowdBonus` 只是在选择群聊时给成员更多的群一点额外权重，不会把不在群中的角色拉进来；会话参与者始终来自真实团体成员。`replyDelayMinutes` 只把回复安排在稍晚的模拟时刻，不改变发送者与历史记录。作息、忙碌、手机和睡眠仍然独立生效，狂欢也不会让睡眠角色发言。

## 性能与降级

“视觉效果等级”包含关闭、低、标准、高。`data-motion` 同时作用于 CSS 和演示层：

- **关闭**：移除非必要背景、粒子、扫入、世界切换演出，并把过渡时长压到近乎即时；暂停、未读、错误和事件状态仍有静态提示。
- **低**：取消背景漂移、扫描与视差，减少装饰层。
- **标准**：默认，低性能设备（设备内存/CPU 受限、Save-Data、减少动态偏好）自动降到低。
- **高**：启用角色剪影浮动和完整环境层。

所有持续动画只使用 transform/opacity，不触发布局；装饰层不是模拟器依赖。世界暂停时环境动态同步暂停。页面卸载会清理 HUD 定时器、媒体查询监听、过渡定时器和路由定时器。

## 验收记录

- 浏览器实际检查：1440×900、1366×768、390×844、320×700，无横向溢出。
- Playwright：界面模式持久化、视觉等级持久化、五档活跃度不触发内容生成、经典界面持久化。
- 长聊天：2000 条消息、100 条渲染窗口、程序化滚动约 62fps。
- 动画层级：高等级开始世界运行时 12 个运行中的 CSS 动画；关闭等级为 0。
- 模拟时钟：AI 请求阻塞期间继续前进，暂停时冻结；界面的 18 次快速导航后无残留过渡层。
