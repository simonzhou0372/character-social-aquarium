# 关系图、东方资料与认知管理更新

日期：2026-10-25。

## 使用入口

- **关系网络**：选择紧凑／分组布局，拖动平移，滚轮或双指缩放。“适应全部节点”恢复全貌。点人物编辑档案，点有向连线编辑关系；键盘 Enter／空格也可打开详情。
- **导出 PNG／SVG**：导出当前世界及团体筛选范围内的完整图谱，不只截取视口。聚焦时的淡化效果不会写进导出。PNG 最长边限制 8192 像素、总像素限制约 2400 万；超大图建议用 SVG。头像只嵌入已保存的本地图片，不发起外部头像请求。
- **世界与团体 → 运行与知识 → 背景实体与认知范围**：默认可看全部已有记录。选择对象查看基础资料，选择知情角色载入对应认知程度；可直接编辑原条目、补充新信息或只修改程度。编辑不重置原知情时间，不改写其他角色的记录。背景实体转为互动实体后，已有认知仍可查看和编辑。
- **世界与团体 → 东方世界 → 人物与关系校准 → 预览新版差异**：可只补关系，不删除历史。锁定关系、用户修改过的字段及世界内覆盖继续受到保护。

## 布局与数据边界

紧凑布局会尝试 25 种候选行宽，以占用面积及长宽比评分选取结果，是确定性的启发式装箱。分组布局优先使用团体归属，未归组人物按连通分量聚合，再排布各分组。多团体人物只出现一次；筛选范围内的孤立节点不会丢失。节点尺寸包含换行姓名，节点之间有间距。布局不修改底层人物关系。

默认适应全图时，大型世界的节点文字会变小，需要放大阅读。防止节点重叠不等于所有连线均无交叉；密集关系图可以按团体筛选或高亮人物来阅读。

东方预设 v3 共有 176 份人物档案、342 条有向关系（v2 为 182 条）。新增关系附有原作出处，参数按两个方向分别定义。高熟悉并不自动意味着高信任，单方面景仰也不会变成对等亲密。表达提示强化既有性格，不增加未经确认的亲属、恋爱或共同经历。未确证的关系不为凑数量而生成。

## 验证范围

- `npm test`：16 个测试文件、234 项测试通过。包括两种布局各 500 个节点的全量保留、边界和无重叠断言，长姓名、孤立节点、确定性排布；v2 差异升级、旧关系保留、非均值参数及不对称关系；认知编辑、时间保留、跨世界校验及备份恢复。
- `npm run build`：通过。仍有既有的大包及静态／动态导入重叠提示。
- 浏览器回归共 25 项通过（`app.spec.ts`、`four.spec.ts`、`round-five.spec.ts`、`graph-knowledge.spec.ts`）。
- `tests/e2e/graph-knowledge.spec.ts`：桌面 1440px 和手机 390px，覆盖 105 节点两种布局、缩放、拖动、适应全部、PNG／SVG 完整导出、人物详情及既有认知的编辑和刷新持久化；手机额外检查双指缩放；切换至东方世界后确认全部 143 个节点可见，旧团体筛选自动清空。
- `tests/e2e/round-five.spec.ts`：世界人物导入、增量扩展、小说模式、东方双重确认重建的桌面／手机回归。

README 图片由隔离浏览器中的演示世界截图生成，只有运行时设置 `CAPTURE_README=1` 才重新写入文档图片。未读取用户的 API 密钥，未调用付费模型，未操作用户浏览器存档；实际模型的措辞表现不作为本次测试结论。
