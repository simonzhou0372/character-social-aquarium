# 第四轮：紧急修复与增量功能

验证日期：2026-10-23。仅在隔离测试数据库与浏览器上下文中验证，没有修改用户存档或读取用户保存的密钥。本轮模型响应使用测试 Provider 与拦截的兼容 HTTP 接口；不将协议测试当作真实模型语义效果证明。

## P0 根因与修复

1. 旧调度链在生活事件提交之前等待 AI；时间栏又依赖提交检查点和固定补全目标，慢请求造成“时钟卡住”。现在 `clockAnchor` 表达时钟锚点，`simTime` 表达已提交进度；浏览器使用 `deferContent` 将生活事实先提交，再由持久化 `contentJobs` 队列生成内容。时间栏独立刷新，落后的生活进度、AI 等待和失败任务有可见状态。晚到消息按原事件时间归档，标为补全记录；不改变历史发送者和来源。
2. 顶栏与时间栏原先各自订阅检查点，暂停动作可能根据较旧的订阅结果反向切换。控制入口现在传递明确运行意图，并在操作时重新读取检查点。控制版本与取消信号阻止旧任务在暂停后提交未来内容。
3. 创建草稿把完整资料字段当成必填，并在一个角色有问题时拒绝整个结果。现在基础名称足以创建可编辑草稿，可选资料有默认值；按对象保留有效内容，显示具体字段问题。截断时只提取原文中完整闭合的对象或字段，不猜测补括号。失败后保留已完成草稿，支持逐角色采用和补生成。
4. 线下对白建议数原先同时充当整场硬上限。现在先规划阶段，逐阶段生成、校验和保存；对白建议数与结构安全上限分离。长对白按 Unicode 字符安全分段，超过单阶段展示条目数则建立连续阶段；失败时保留检查点，继续时只生成缺失阶段。
5. 新图片样式曾与旧世界卡片装饰层同名，造成透明层遮挡按钮；浏览器回归发现后已限制为图片元素。

核心文件：`src/core/time.ts`、`src/core/engine.ts`、`src/ai/content-queue.ts`、`src/ai/drafts.ts`、`src/ai/scenes.ts`、`src/components/WorldHUD.tsx`。

## 新增能力

- 世界关系图和角色关系编辑支持 AI 关系草稿：单人、多人、团体、世界范围，有向边预览、编辑、逐条／批量采用、删除、局部重生成。保存时再次检查端点与锁定关系。
- 世界封面与会话头像沿用既有本地图片裁剪；私聊、群聊、场景支持自定义标题和恢复自动标题。成员同步不会覆盖自定义标题。
- 聊天支持首条未读定位、按所扮演角色调整消息左右位置、结构化角色提及、引用回复及原消息跳转、可追溯 Emoji 回应、独立的观察者与角色逐消息阅读记录。历史记录窗外的跳转会加载目标附近内容，不伪造副本。
- GIF 图库使用 Blob 资源去重，支持命名、标签、搜索、收藏、移除与关闭动画。继承顺序为角色、当前团体、世界；同名资源覆盖，其他团体私有资源不会进入当前聊天的可用列表。AI 只收到授权资源元数据，生成的资源 ID 再次校验。移除资源不破坏历史消息显示。
- 大型事件配置支持虚拟日间隔、3／7／30／90 天预设、事件倾向、关系影响和多团体范围。截止期与序号持久化，不依赖概率碰巧命中；已有符合条件的自然事件可纳入本轮周期。关系影响有界、只作用于实际参与者的未锁定关系，默认禁止破坏性后果。
- 大型事件聚合通知、历史通知中心、已读筛选与详情关联线上聊天和线下场景。失败细节可继续生成，暂停不推进事件周期。

## 数据兼容与诊断

数据库从 v6 增量升级至 v9：v7 新增内容任务和时钟锚点；v8 新增资源、GIF、回应与阅读记录；v9 新增大型事件、截止期与通知。旧资料、头像、消息、API 配置和自定义提示词保留。完整 JSON 备份增加新表及资源编码，恢复前检查引用、文件结构和 SHA-256；运行中的任务恢复为待处理，世界安全暂停。世界观包仍以设定和成员为主，完整聊天、GIF 与通知归档使用“本地数据 → 完整备份”。

回退继续创建独立分支，重映射消息引用、GIF 世界作用域、阅读与回应记录、事件通知和待处理任务，不改写原世界。回退沿用当前角色与关系设定，无法恢复未版本化的旧人设。

浏览器开发工具可执行 `window.aquariumDiagnostics()` 查看最近调度、提交耗时、显示时间、倍率和队列状态。诊断仅存在有界内存中，不按秒写数据库。顶层未读计数改用会话序号索引，避免每次检查点更新都加载完整消息历史。

## 边界

- 浏览器关闭期间没有后台服务器；重新打开后按真实离线时长补全，前台倍率不会乘到离线时间。
- 语义质量仍取决于用户所选模型。未知兼容服务默认采用 JSON 文本，可在高级设置明确选择结构化模式；服务商不支持的参数会单独分类提示。
- 大型事件的规则调度事实可以先保存；AI 细节或线下阶段失败时显示待恢复，不以伪造对白代替模型结果。
- 不限制总用量仍保留单请求输出额度、并发上限、超时及有限重试。低性能设备补全整月可能耗时较长，进度和内容积压会显示，原始记录不因此裁减。
