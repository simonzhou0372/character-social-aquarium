# 第三轮：选择性观察、人物演化与世界报告

在现有模拟器、内容队列和 IndexedDB 中增量实现，没有清空存档或创建第二套聊天系统。交付同时包含工作区已有、尚未提交的第四轮修复，见 [第四轮记录](ROUND-FOUR-VALIDATION-2026-10-23.md)。

## 实现与验收对应

| 范围       | 实现和验证                                                                                                                                                                                      |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 观察管理   | 世界页和设置页提供全量／选择性模式、角色／团体搜索与批选、CP 选择、范围预览和观察／静默统计。已有世界默认全量，新世界保存明确选择的范围。手机操作与刷新持久化有浏览器测试。                     |
| 真正静默   | 调度只加载活跃角色及状态，按范围过滤私聊、群聊、共同活动和 AI 任务。团体不会激活成员的全部私人网络，关系不递归扩张。取消观察保留历史并挂起无关内容任务；重新观察可恢复。                        |
| 必要参与者 | 明确待回复的观察角色消息可临时引入有限接收方；低频宏观事件只抽取直接相关的强关系对象，不将其加入完整观察范围。主事件、参与者私有记忆和后续聊天共用事实引用。                                    |
| 三天回溯   | 以已提交世界时间向前覆盖 72 小时，受故事起点限制；每次处理一个虚拟日，持久化范围、提示词快照、检查点和内容任务。查询已有活动占用，稳定事件 ID 避免重复写入。暂停、取消和继续不删除历史。        |
| 完成判定   | 时间范围检查完毕但 AI 内容未完成时显示等待／失败，不伪报完成。移除部分对象后，它们的挂起任务不会阻塞剩余对象。已覆盖区间不重复生成。                                                            |
| 人物演化   | 每世界独立开关，默认关闭；角色可授权主动性、性格、语言风格、习惯四种字段，核心身份不可写。依据真实参与事件，主动性每次变化不超过 0.05，结果存世界成员覆盖层。关闭后停止新增演化，保留已有变化。 |
| 撤销与历史 | 保存前后值、原因、来源和依赖链；撤销后续依赖需级联确认，检测手动修改冲突。历史对白按当时演化值和知情时间组装，避免提前使用未来成长和后来传播的知识。                                            |
| 五类报告   | 日／周／月／季／年独立开关，默认全关；按整数虚拟历法归档，支持六位年份。暂停不新增归档，长跨度分批登记、稳定 ID 去重。                                                                          |
| 报告事实   | 检索观察范围内事件、聊天、场景和演化记录，长周期复用下级来源并保留重要原始事实。默认本地整理，用户可按需请求 AI 选择结构与事实引用。未知引用拒绝，正文展示原始事实，报告不写入角色共同知识。    |
| 报告界面   | 世界、类型、虚拟日期筛选，待生成状态和生成按钮；人物、事件、聊天、场景来源可跳转。独立报告提示词允许标题，不套用角色聊天的 Markdown 禁令。                                                      |
| 数据安全   | 数据库 v10 新增七个集合及范围索引。旧存档保留全量观察、报告关闭、演化关闭。备份保留新增记录，世界包重映射观察引用，回退分支排除未来事实，新故事知识映射到新时间起点。                           |

## 负载对比

固定种子的同一百人、十团体世界，分别运行全量观察和只观察五名角色及一个团体，相同八个虚拟小时内，AI 内容任务 **23 → 6**，减少约 **74%**。这是实际调度队列计数，使用故障注入 Provider 验证，不是付费模型 Token 实测。

选择性模式保留活跃档位参数，按活跃人数占比的平方根折算世界级机会总量；全量模式不改变既有三档校准。另测五百名静默角色不会为这些角色新增细粒度状态、普通事件或社交任务。原状态与历史保留。

## 验证方式与边界

- 单元／集成覆盖范围去重、A→B→C→D 不级联、静默人物必要影响、三日回溯与占用、AI 未完成状态、世界隔离、锁定和依赖撤销、历史知识边界、报告周期和事实引用、百人负载、五百静默实体、v9 迁移和备份恢复。
- Chromium 新增四条流程：手机观察配置持久化、72 小时自动回溯、23456 年年报及事件跳转、字段授权与演化撤销；同时回归已有聊天、世界创建、线下场景和第四轮流程。最终数量见 [验证总表](VALIDATION.md)。
- 本轮没有发起新增付费 API 请求。协议、错误和提示词通过注入 Provider 与浏览器拦截验证，不能据此证明任意真实模型的文风或推理质量。
- 无时间戳的旧知识视为初始已知设定，无法追溯真实获知日期；未版本化旧基础档案也不能自动还原。新传播记录带获知时间。
- 演化最多每七个虚拟日评估一次、每次最多八个候选。规则路径只缓慢调整主动性，文本字段需 AI 建议并经相同证据／锁定检查；失败不高频重试。
- 回溯生成代表性经历，不逐分钟填满三天；已占满历史只保留事实和说明。报告为事实抽取式呈现，AI 可优化结构，不自由编写无引用叙事。
