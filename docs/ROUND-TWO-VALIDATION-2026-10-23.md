## 活跃度校准

完整样本：[ACTIVITY-CALIBRATION-2026-10-23.json](ACTIVITY-CALIBRATION-2026-10-23.json)。

| 档位 | 平均消息数 / 模拟日 | 相对安静 | 平均主动发起次数 |
| ---- | ------------------: | -------: | ---------------: |
| 安静 |               38.67 |    1.00× |            19.33 |
| 标准 |              110.00 |    2.84× |            46.00 |
| 热闹 |              225.33 |    5.83× |            70.00 |

校准世界提高可社交性、关闭工作抑制并固定主动间隔，用于比较调度器，不代表每个真实世界必定产生的消息数量。睡眠、用户控制、关系、手机习惯与预算仍会改变实际结果。协议测试响应每次两条消息，真实模型可能选择短句、沉默或不同条数。

线下共同活动机会按模拟时长折算，抽样比例与每日场景数另设，未使用网聊档位乘数。单场对白预算按活动时长与重要性分配。代表性生活描述最多每六模拟小时一次，避免每次网聊前追加调用。

## 运行边界

- 当前是本地应用；关闭浏览器后通过下次打开时补全，后台没有常驻生成服务。
- 沿用之前明确配置的离线 1× 策略：前台可加速，后台/关闭/断网期间不将现实时间乘以倍率；两种模式暂停均冻结。
- 历史回退保留原时间线，复制目标之前的记录；跳到任意故事日期建立无旧事件的新分支，不移动原始历史，也不补全虚构年份间的数万年。
- 旧数字时标完整保留，通过世界日期锚点映射，避免大年份毫秒精度溢出。没有使用原生日期控件或依赖字符串解析来处理虚构纪年。
- 场景每条对白硬上限 300 字，与网聊 1～3 条及其长度规则分开；Markdown 和通用行为禁令仍约束角色对白，内部 JSON 不受影响。
- 本轮新增 AI 流程使用本地结构化 Provider / 网络测试响应验证，未额外调用付费 API。上一轮真实 DeepSeek 无人干预验证位于 `LIVE-DEBUG-2026-10-22.json`，它不作为本轮新增场景模块的实模验证。
- 构建只有常规单包大小提示，无编译错误。未发布或覆盖用户在线站点。
