# 东方可选头像素材

仓库只包含出处、画师和下载地址目录，不包含立绘图片。首次启动、安装预设和打开素材页面均不会下载图片，也不会为此调用 AI。

入口：世界与团体 → 东方世界总览 →「东方头像素材（可选下载）」；也可从设置 → 本地数据进入。选择角色后点击「下载并应用」，图片保存到当前浏览器本地数据库。支持搜索、批量选择、进度、取消、失败重试和清除下载；手机端同样可用。

## 选图范围

当前 176 个角色档案中，153 个有经过画师分类和角色名称核对的候选立绘：44 个优先黄昏边境作品绘，109 个采用 ZUN 绘。黄昏作品包括 alphes、春河萌及 TOKIAME 的绘制，不将这些作者混称为 alphes。候选顺序优先黄昏作品，再回退到 ZUN 原作。

Windows 与 PC-98 分开匹配，两只铃仙不混用。23 个暂缺符合条件的单人立绘档案保留程序默认头像，可切换「暂缺对应立绘」查看原因。这不表示角色没有任何官方视觉资料；例如三妖精的《妖精大战争》立绘属于比良坂真琴绘，不能冒充 ZUN 绘或二创填补。

每个候选均提供原图说明页、作品与画师。目录来自 THBWiki 的官方游戏立绘及对应画师分类；这是素材出处记录，不是本项目取得图片再分发授权的声明。请遵守[东方创作使用指南](https://touhou-project.news/guideline/)以及[黄昏边境作品方条件](https://tasofro.net/touhou/faq.html)。官方图片不属于本项目的开源授权范围。

## 本地保存与保护

- 默认只给空头像下载图片，已有自定义头像保留。更新开关也只允许更新此前通过此入口安装且内容未变的图片。
- 下载期间手动换图，不会被稍后完成的下载覆盖。
- 清除素材需要确认，只清除内容与下载记录一致的头像，不删除角色与历史。
- 已完成项逐个保存，中断后可重试剩余项；最多两个并发请求，每个候选最多等待 20 秒，最多尝试三个已核对候选。
- 获取 256 像素缩略图，校验文件类型、1 MB 上限及浏览器解码。请求不携带凭据、API 密钥、角色信息或聊天内容。
- 图片与出处记录随现有完整本地备份导入导出，刷新不会丢失；清空浏览器站点数据前应先备份。
- 下载依赖素材站可用性；网络、跨域或防盗链错误会明确计入失败，保留原头像，可稍后重试或通过现有角色头像上传功能自行选择图片。

## 维护目录

执行 `python3 scripts/catalog-touhou-portraits.py` 重新查询元数据并生成 `src/data/presets/touhou-portraits.json`。脚本不下载图片。目录变更不会自动替换用户现有头像。
