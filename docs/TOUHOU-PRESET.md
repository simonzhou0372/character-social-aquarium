# 东方Project 内置原设资料预设

整理日期：2026-10-25。本预设是基于原作的非官方事实整理，不是官方授权新作，也不把随后生成的聊天、生活事件或报告当作正史。

## 内容与边界

程序内置两套互相独立的世界：

- **幻想乡原设资料**：143 份角色档案，覆盖红魔乡至锦上京整数作、主要黄昏合作作、三妖精及官方书籍的重要角色和背景人物。
- **PC-98 旧作档案**：33 份角色档案，覆盖灵异传、封魔录、梦时空、东方幻想乡、怪绮谈。与后作重合的角色按版本分开，不将后作经历直接写入旧作。

两套合计 **176 份档案、82 处地点、33 个团体／从属体系／观察分组、342 条有向关系**。档案数量包含同一角色的旧作版本及背景人物，不等于 176 个同时在场的独立人物。

这是尽量覆盖已核对内容的资料集，不声称穷尽所有连载章节、匿名配角、装置、召唤物或未使用素材。不为填满名单而编造性格、能力、家谱、生日或恋爱关系。缺少足够人格资料的角色、已故者、行踪不明者、未来外界角色等默认作为背景资料，不自动生成日常生活。

## 出处

每个角色、团体与关系保存 `provenance.sourceIds`。世界编辑页可搜索地点、查看通行边界和出处；角色、团体、有向关系编辑页可展开“原设资料与出处”。

来源分为三种，并在界面分别标注：

1. 官方页面：例如 [东方Project作品介绍](https://touhou-project.news/touhou_project/) 与 [一迅社茨歌仙人物介绍](https://www.ichijinsha.co.jp/special/toho_ibarakasen/)。
2. 原作附带文档的转录与翻译：例如 [附带文档索引](https://omake.thwiki.cc/)，对应 ZUN 撰写的角色设定；只自行概述事实，没有在程序中收录文档全文。
3. 官方作品／章节索引：用于定位官方漫画、设定集和音乐CD的原作资料，不将百科推测与二创解读当作原作。

具体清单在 `src/data/presets/touhou-sources.ts`。例如 [锦上京原作附带文档转录](https://omake.thwiki.cc/translate/东方锦上京_omake.zh.txt) 用于核对新增角色；[儚月抄设定页转录](https://thwiki.cc/index.php?setlang=en&title=东方儚月抄_～_Cage_in_Lunatic_Runagate./设定文档) 用于区分两只铃仙和绵月姐妹的关系。

本项目明确为非官方，仓库不收录游戏立绘、音乐、原始脚本或结局全文。头像默认使用程序绘图；用户可通过[可选头像素材入口](TOUHOU-PORTRAITS.md)自行选择下载。官方图片不属于本项目开源授权范围，需遵守[官方创作使用指南](https://touhou-project.news/guideline/)及作品方条件。

## 不混用的设定

- 大妖精、小恶魔作为通称标注，未公开的姓名与人格不补写。
- 神绮与爱丽丝的母女关系、梅莉与紫的同一身份、堇子与莲子的确切家谱、封兽魑魅与鵺的血缘，均不作为已确认关系。
- 普莉兹姆利巴的骚灵与原人类家庭区分；命莲、蕾拉不自动复活。
- 永远亭铃仙与儚月抄的另一只月兔分开；现代堇子与未来秘封俱乐部不默认处于同一时代。
- 原作明确存在疑问时继续保留，例如百百世的“噬龙”能力标称不被改成已经证实的战绩。
- “观察分组”只用于资料整理，默认作为背景团体，不创建原作没有的社团或共同群聊。
- 关系数值为差异化、可不对称的软件模拟参数，例如熟悉不等于信任，单方面仰慕不等于双方亲近；不宣称原作存在某个好感度分数。关系事实默认锁定，默认不开人物演化。角色表达提示可以强化原有性格的表现，但不能改变原作事实。

## 安装与运行

`App` 在原有初始化后调用 `ensureTouhouPresets`，每个新部署的浏览器默认获得两套资料。已有用户同样补入，但原世界、消息、API、提示词和当前选中世界不被覆盖。第一次安装在本地事务内完成，不需要模型生成或外部服务。

安装版本记录在设置的 `installedPresets` 中。后续启动不改写用户编辑的预设，也不会把已经移入回收站或永久删除的预设重新塞回。该记录及原设出处随完整备份保存；世界包包含对应角色、团体、地点与关系资料。

世界默认暂停、1×、真实AI模式，选择性观察少量主角；没有默认伪造聊天、生活事件或共有记忆。浏览资料不需要密钥，启动内容生成时沿用用户的接口配置。**本次开发没有调用付费模型。**

日期使用“观测历”，作息、活跃度和地点起点均明确是程序参数，不冒充原作固定日程。角色日常活动限定于各自活动范围，共同事件只能选取参与者活动范围的交集。实时规划、历史回溯与静默人物临时介入均遵循该范围；不因世界拥有月都、天界等地点就随机把地上角色送过去。将角色显式加入其他自定义世界时，不把预设地理限制强加给该世界。

完整地点说明与全部出处只在资料页面或备份中保留，AI请求不会携带整套地点说明与参考书目，避免大型预设导致上下文膨胀。

## 更新已有存档

v3 补充有出处的关系并校准表达提示。已安装的世界不会被启动逻辑自动覆盖。进入“世界与团体”，切换至对应东方世界，展开“人物与关系校准”，点击“预览新版差异”。可以只补充缺失关系，也可以逐项接受资料更新。

升级器识别 v1、v2 的未修改默认值；用户自定义内容及锁定关系受到保护。已有消息、事件和记忆不因补关系而重写。无需使用“删除旧东方历史并重建”就能获得缺失关系。
