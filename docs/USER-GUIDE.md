# 使用浮游

## 开始观察

首次打开会出现引导。选择「先看看演示世界」，可以认识五位原创角色，浏览现有聊天和生活记录。演示对白有「演示」标识，不能代表真实 AI 生成。

在「世界设置 → AI 设置」选择服务商，填写 API Key 和模型名称；高级连接设置可以修改 Base URL。模型名称留空时，测试按钮尝试读取可用模型列表，选择后再次测试。「保存配置」将应用设置保存到当前浏览器。默认不持久保存密钥，重新载入页面后需重新填写；勾选保存则仅在本地数据库保留。

主导航底部的「开始观察」启动当前世界。无 Key 时运行规则与明确标记的演示对白；连接 AI 后启动会采用真实生成模式。默认新世界使用上帝模式，前台可加速；五个世界分钟以上的有效时间段会被提交，不会每秒请求模型。短时间没有消息是正常情况。

## 创建世界和角色

程序已内置“东方Project · 幻想乡原设资料”和“东方Project · PC-98旧作档案”。无需手动导入，启动后在切换世界或“世界与团体”中进入。默认暂停并选择性观察少量主角；可自由调整观察范围，其他资料仍然存在。背景人物不自动生活或发言。

编辑世界展开“原设资料与出处”可搜索地点、查看通行边界；角色、团体和关系编辑窗口也有出处入口。界面明确区分原作事实与软件调度参数，新生成内容不是官方正史。详细范围见 [东方预设说明](TOUHOU-PRESET.md)。

「世界与团体 → 创建世界」填写名称、规则、场景、时区、故事基调。世界规则是事实约束，不会被全局角色口吻覆盖。

「角色图鉴 → 添加角色」配置名字、来源、简介、性格、说话与生活习惯，可加入多个世界。在「当前世界专属设定」覆盖此世界的人设和口吻，其他世界仍使用原有配置。已有成员关系暂不提供删除，避免破坏历史引用。

角色头像支持文件选择或拖拽。上传后缩放裁剪，保存后随完整数据备份一起导出。默认头像是应用原创矢量插画。

「AI 帮写」需要有效 API。建议先填写作品与名字；生成后在预览中核对推测内容，逐项采用，不会自动覆盖资料。

创建团体时至少选择两位同世界成员。每位角色可参加多个团体；团体有自己的会话。已有消息的成员不可直接移除，避免历史发送者成为孤立引用。

## 关系与聊天

关系网络中的连线有方向。夏生对澪的昵称、亲近、信任、边界，不会自动变成反方向的值。点击连线可编辑，点击角色可查看资料；下方还有适合手机操作的关系列表。

打开聊天会更新观察者的已读位置；角色是否读过消息由他们的手机状态决定。你看过某条消息，不会让角色自动读过它。向上翻阅时，新消息不会强制拉回底部。

默认「只观察，不参与」。聊天输入区可以选择以自己参与，或扮演会话里的某位角色。扮演时，你的消息归属于此角色，AI 不会为该角色生成新台词。切回观察或自己后，角色重新由系统接管。历史消息发送者不会因为切换身份而改变。

角色睡觉或忙碌时可能不会立刻回复。开启模拟后，未来的手机机会、阅读和社交决策会决定何时继续聊。

## 全局提示词管理

入口：「世界设置 → AI 设置 → 提示词管理」，也可直接点击设置页的「提示词管理」标签。

七类提示词分别控制行为语言、生活模拟、离线补全、社交、资料帮写、长期记忆和线下互动。每张卡片有编辑器、启用开关、修改时间、字符数及估算 Token 数。编辑或开关修改后点击该卡片「保存修改」。未保存内容不会用于 AI 请求。

「恢复默认」先展示默认全文，确认后只恢复当前分类。「恢复全部默认」恢复七类提示词和消息生成规则，也需要确认。导出提示词 JSON 可以独立备份；导入前会展示内容，确认后替换。

下方「消息生成规则」设置条数、软建议字数、硬上限及是否允许格式/描写/沉默/自主聊天，点击「保存生成规则」。软建议不禁止「嗯」「好」之类短句。硬上限与合法身份由程序验证；违规响应不会写成部分消息。

新请求立即读取新版本。正在进行的离线补全继续采用开始时快照，即使刷新后恢复，也不会混用不同规范。过去的聊天不会被重写。Token 数只是字符启发式估算，不等于模型精确分词结果。

## 生活、离线恢复与记忆

时间轴支持日/周视图、日期跳转、缩放和角色/团体/类型筛选。点击活动查看成员、地点和持续时间，并打开相关会话。

「世界知识库」支持输入或导入 TXT/Markdown，并明确选取知情角色。其他角色不会检索到这份私人知识。聊天顶部的书本按钮按需整理长期记忆；摘要保留在会话参与者范围内。

关闭浏览器后没有程序继续运行。重新打开运行中的世界时，应用根据时间差分段恢复生活、社交与必要消息。长跨度采用较少代表性聊天，日程仍保留小时边界。进度界面显示实际提交进度、事件数与消息数。可以安全暂停，随后从最后提交点继续。API 出错时已提交内容保留。

## 保护你的世界

「世界设置 → 本地数据 → 导出全部数据」备份世界、角色、头像、消息、事件、检查点、记忆与提示词。API 密钥不在备份里。

恢复时先校验并展示数量，确认后完整替换当前数据，模拟暂停并清除 API 配置。恢复前先导出当前数据。浏览器清理站点数据可能删除全部记录，建议定期备份；「申请持久存储」是否成功由浏览器决定。

## 本次更新：创建整套世界与时间控制

「世界与团体」页面现在直接展示当前世界角色，可以新增或编辑角色，不必回首页。

「添加世界观」弹窗可勾选已有角色和团体（团体成员会一起加入），也可按行新增角色和团体。填写少量资料和「AI 生成约束」后，可以生成世界规则、人物完整资料和团体成员的整套草稿；先预览、修改、采用，再保存。约束可写人数、作品/AU、基调和关系边界。生成不会自动覆盖已有角色。

「创建团体」也支持已有成员、新角色和 AI 草稿。当前世界的角色会高亮；点选世界外角色会先确认，保存团体时才把角色同时加入当前世界。取消或关闭弹窗不会写入这些临时选择。世界观包可以单独导出，再用「导入世界观包」在另一个站点导入；导入会创建独立资料，保留已有世界。

世界页的「时间控制」和「设置 → 模拟器」可切换：

- **上帝模式**：新世界默认 30×，前台最高 3600×。关闭页面、进入后台或断网后的时间，只按现实 1× 补全。高倍率会更快使用 AI 预算。
- **真实世界模式**：始终 1×，不提供加速与回退。暂停会冻结世界；关闭后重新打开仍暂停，不补算暂停期间。消息可能要等几十分钟甚至数小时，沉默、工作和睡眠都很正常。

「回到某一天」按选择的世界年月日时分创建新时间线，保留原世界，复制目标时间之前的事件、消息与记忆，排除未来记录。它使用当前角色/世界配置，并不声称能恢复过去版本的人设。回退后新时间线暂停，可检查后开始观察。

角色资料中的「自主行为与日程」现在可设置主动发起方式：按时间间隔、仅重要事件、几乎不主动。间隔用世界分钟表示，比如 30 分钟或 240 分钟。间隔到了只是开始寻找适合开口的机会；睡觉、忙碌和手机不可用仍会阻止发言。回复别人的消息不会重置主动话题的间隔。

时间轴默认跟随当前世界日期，**最新事件在最上方**。「回到最新」可结束历史日期浏览。

## 回复格式、截断与上下文压缩

应用将输入预算与输出预算分开。在 AI 高级连接设置中可修改，默认输入预算为 32,000 Token、普通输出预算 2048 Token。输入预算允许手动设置到 1,000,000，但需依据实际模型窗口并为输出和思考留出余量；这不是实际发送量，系统仍压缩无关历史。已有手动配置不会被覆盖；如之前已保存为 4000，请在此处改为 32000 并保存。

每次请求优先保留全局规则、世界事实、角色身份、锁定关系边界、当前状态及最新用户消息；省略头像等外观数据，按相关性保留少量记忆，并缩减较早的聊天。它在本地做摘取，不调用额外模型编造摘要，也不删除原聊天。必要事实自身超出预算时，会明确提示调整预算，不会悄悄截掉规则。

截断或无效 JSON 会最多自动恢复一次，使用更紧凑上下文与有限的更高输出额度。代码围栏、消息数组括号错位可以安全兼容，但发送者、条数、文本长度、时间偏移仍必须合法。正文不会按换行符拆分。

如果仍然失败，你发送的消息会保留，可点击「重试回复（不重发你的消息）」。AI 设置页会展示最近请求的压缩前后估算及省略数量。已知的 DeepSeek 日常模型默认关闭深度思考，避免简短聊天的输出额度被推理占用；可在高级选项调整。

## 第二轮：世界时间与线下观察

主界面顶部始终显示当前世界的纪年日期、运行状态、暂停/继续按钮和倍率菜单；手机也直接可用。速度只改变虚拟时间映射，不等于 API 请求频率。每个世界保留自己的时间状态。

创建世界时填写纪年（默认 AD）及“故事从哪一天开始”，年份可以是 30、23456 或 999999。年月日时分独立输入，非法闰日无法保存。当前版本采用公历式月份与闰年规则。修改纪年不改变事件顺序；要跳到一个全新的故事日期，在上帝模式时间控制中选择日期并确认“从指定日期开启新故事”。新分支沿用角色 ID、关系、团体及知识，不搬移旧事件。历史回退则只复制目标之前的记录。

“线下观察”位于导航和手机底栏。历史卡片按最新时间排列，支持世界、团体、地点、类型、时间范围和多角色任意/全部匹配。打开后按阶段阅读，对白与活动说明分别展示，可点击阶段跳转。精选时间轴中的“查看线下对话”打开同一场景。

模拟器独立抽样共同活动生成线下内容。设置 → 模拟器可调整抽样比例（默认 50%）与每世界每天场景上限（默认 3）；长活动和重要事件有更高对白预算。它不随网聊三档一起乘六倍，也不会要求每分钟都出现对话。离线补全共用此规则。生成失败保留主事件与已有网聊，在线下观察说明原因。

角色资料可设置任意性别文本或留空，AI 建议需逐项接受后再保存。选择“背景人物/传闻人物”或“背景团体”后不参与自动生活、聊天或线下场景。在世界页“背景实体与认知范围”添加知情角色、程度、已确认事实/传闻/错误传闻/个人看法及来源。名气不等于全员知晓；实际读到或在场听到的明确内容才传播，不复制发言者的整份私有资料。转换回可互动模式保留 ID 与既有认知。

时间轴默认“精选事件”，普通睡眠、休息等仍保存在底层；切换“全部事件”或“日常状态”查看。连续同类普通状态在观察层合并，不删除原记录。

设置 → 模拟器可以上传、拖入、更换或恢复用户头像；校验图片后缩放裁剪并保存。用户自己发言用用户头像，扮演角色时用该角色头像。完整备份包含两类头像。

“不限制模型用量”取消应用累计用量限制，关闭后原限额继续生效。提供商额度、限流、并发和有限重试仍有效；独立线下密度设置仍可控制成本。API 用量在设置顶部持续显示。受到应用预算限制时会明确提示，可调整预算或开启无限制后继续。

## 第四轮新增操作

### 观察范围、人物变化与报告

世界页的观察摘要或“设置 → 观察管理”可选择全量／选择性观察。角色、团体和双人关系可以重叠选择，不会重复模拟。观察团体只包含团体相关活动，不会展开成员的全部私人社交。取消观察保留原聊天与事件，停止后续无关细节生成。

新增观察目标会回溯已提交世界时间之前的三个虚拟日，最早到故事开始。面板显示日期范围、分日进度与内容数量；可取消、继续。世界暂停时任务等待恢复。时间范围检查完成但 AI 内容失败或尚在排队时，仍标记未完成，可在内容任务中重试。

编辑世界可开启“允许人物设定随经历自然变化”，再在角色的当前世界设置中授权可演化字段。未授权字段与核心身份不会自动改写。人物变化记录显示来源、原因及前后值；撤销涉及后续变化时需要确认级联撤销。关闭演化会停止新变化，保留已经经历的成长。

导航“世界报告”可独立开启日、周、月、季、年报。周期使用世界模拟时间和纪年。默认本地整理已有事实，不为写报告额外编造日常；历史待办可按需生成，也可请求 AI 优化结构。来源按钮可以回看人物、主事件、线上聊天和线下场景。报告不会自动成为所有角色的共同知识。

- **运行状态**：顶部时钟持续显示世界时间；“内容积压／AI 等待／生成待恢复”可打开持久化任务列表并重试。暂停后等待状态显示“已暂停”再关闭页面。生活进度落后时显示积压分钟数，模型等待不会固定住显示时钟。
- **AI 草稿**：世界／团体创建中只写一句约束也能生成基本资料。展开角色可编辑或单独采用；采用只填表，保存按钮才写入世界。缺字段与截断会保留完整部分，补生成不会清空已有成功草稿。
- **关系**：在关系网络或角色关系编辑中打开“AI 生成关系”。可选择角色、团体或整个世界，填写要求；预览支持修改亲近、信任、熟悉和背景，逐条采用，锁定关系不会覆盖。
- **图片与名字**：世界编辑支持封面上传和裁剪。聊天中的会话设置支持头像与名称；场景详情展开“编辑场景标题”。自定义标题可恢复自动命名。
- **聊天**：用“跳转到第一条未读”定位原消息；切换聊天身份后，该身份的历史消息也显示在右侧，来源标签仍保留。输入时选择 @ 角色，消息上可引用回复、查看回应者和阅读详情。观察者浏览不会让虚拟角色自动已读。
- **GIF**：输入区打开“GIF 表情”，上传时选择世界、当前团体或角色图库，可添加名称、分类、用途说明并收藏。关闭自动播放可静态查看。移除图库项目后，历史消息仍保留原资源。完整备份包含 GIF 二进制资源；不要把世界观设定包当成完整聊天归档。
- **线下续写**：场景显示“阶段未完成”时点击“继续生成”；已完成对白保留，不重新生成整场。这里的对白密度独立于线上活跃度。
- **大型事件**：世界编辑中开启并设置最大虚拟日间隔。顶部提示可收起，历史仍保存在“重大事件”中；支持按世界、已读状态和重要程度筛选，点击详情可查看影响与相关场景。默认关闭自动关系变化，开启后也不会覆盖锁定关系。
