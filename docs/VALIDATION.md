# 验证与边界

验证日期：2026-10-22。当前增量版本已通过 99 项单元/集成测试、17 条浏览器流程；真实 DeepSeek 无人干预与整套创建草稿验证见下方报告。前面早期交付记录保留供追踪。

## 自动化覆盖

- 提示词按六种任务路由、停用、即时生效、只读批次快照、默认升级保护、版本递增与规则范围。
- JSON 数组拆分、换行不拆、常见 Markdown、动作/心理前缀、过长 Unicode 消息、非法发送者、时间偏移、空消息与连续消息上限。
- AI 帮写和记忆整理经过实际 Orchestrator，使用不消耗费用的 Mock Provider。
- 真实 Provider 协议经过浏览器请求拦截，验证自定义规则进入请求并展示为多个独立气泡。
- 日程跨午夜、确定性规划、共同活动无时间重叠、手机/睡眠/角色控制条件。
- 一天离线恢复、检查点中断续跑、重复执行不重复提交、提示词恢复快照版本不混用。
- 知识按世界、知情者和发生时间过滤。
- 导出不含密钥，恢复后暂停，引用损坏备份拒绝。
- 浏览器初次引导、保存刷新、恢复预览/取消确认、提示词导入导出、角色创建、关系网络、时间轴与角色扮演。
- 1440×1000 桌面与 390×844 手机截图；手机主页/提示词/聊天无页面级横向溢出。
- 两个真实浏览器标签页共享数据库，关闭页面后另一个页面接续补全，不产生重复 ID。

常规单元/浏览器自动化不依赖实际密钥，不消耗真实 API Token；后续专项实调则复用了用户授权接口。fixture 可以验证提示词发到模型接口，但不能用 fixture 证明真实模型一定理解日语、角色人格或世界观事实。

## 已知限制

1. **服务商覆盖有限**：本次经用户授权，复用已配置 DeepSeek 做了真实调用；没有创建新密钥。其他服务商仍以协议 fixture 为主，CORS 及模型参数兼容性需具体测试。网络/CORS 在浏览器往往无法精确区分，错误提示明确列出两种可能。
2. **生活复杂度有限**：作息按小时与基础活动规则，短休/排练间隙通过手机概率模拟，没有完整可视化自定义日程编排器。AI 只能描述已确定活动，不能任意改日程。关系标签不自动重写，长期关系曲线仍需迭代。
3. **长期跨度容量**：旧记录仍保留小时活动，消息按预算稀疏补充；每次运行最多 240 个恢复段，超出后留存检查点等待下一次调度，不会一次阻塞界面数年历史。没有百万消息虚拟列表；会话加载最近 100 条，时间轴最多展示 400 条筛选结果。
4. **时间回退边界**：回退创建独立时间线，保留原世界；使用当前设定，不能恢复未版本化的旧人设。时间轴已按世界时区计算日期边界，最新事件在上。
5. **记忆整理**：共同活动自动记录结构化经历；聊天摘要由书本按钮按需触发，没有定期自动 AI 摘要服务。纯词法检索无语义召回保证。
6. **头像裁剪**：支持居中缩放裁剪，暂不支持自由拖动裁剪框。默认矢量头像均为应用原创，不是官方 IP 素材。
7. **用户身份**：每个浏览器一套用户昵称/简介，尚无多套用户 persona 的图形化管理；角色扮演已支持。团体与角色成员为保留历史暂不提供全量删除入口。
8. **多标签页**：现代 Chromium 的 Web Locks 经过浏览器流程验证；不支持锁的浏览器只能防重复提交，无法严格防止并行候选模型请求。未覆盖 Safari/Firefox 的所有存储/PWA 差异。
9. **格式语义**：常见格式标记与长度由程序拒绝，无法用正则证明所有无标记的心理/动作描写都被拦截，也无法证明模型没有编造事实。无效响应会保留历史并显示错误，不自动无限重试。
10. **本地存储**：数据没有跨设备同步，站点源变化后不会自动迁移。API Key 可选择本地明文持久化，不能宣称绝对安全。部署没有附带通用本地代理/桌面安装包。
11. **展示主题**：界面已使用统一主题变量，第一版只交付浅中性色皮肤。PWA 只缓存应用自有静态资源，不缓存任何 API 鉴权请求。

## 本次开发中实际修复

- Dexie liveQuery 内执行初始化写事务造成首次打开提示词页错误：改为组件 effect 初始化、查询只读取。
- 较矮桌面窗口中的固定导航超出视口：导航允许独立滚动。
- 补全取消时丢失待补时间：保留目标与快照，按检查点继续。
- 长跨度事件跨越睡眠/工作边界：粗粒度恢复内部仍按小时边界规划。
- 世界内设定无法清空覆盖：编辑时正确加载，并按输入值保存。
- 空模型名阻止获取模型列表：列表探测与模型验证分开。
- 测试框架 Node 18 与新 Playwright 版本不兼容：固定兼容版本，并提供通用 Chromium 路径环境变量。

## 第一轮增量结果（历史记录）

- 99 项单元/集成测试、17 条浏览器流程通过，含世界页编辑、世界/团体创建向导、世界外角色确认、AI 草稿约束与显式保存、时间模式/回退、最新事件在上、截断恢复、手动重试不重复消息、手机弹窗。
- 增加输入/输出分离预算和本地抽取压缩。保留世界事实、全局规范、锁定边界与最新用户消息，压缩普通旧聊天与低相关记忆，删除头像等外观载荷。缺少空间时明确拒绝，不静默丢规则。
- 截断保留真实 Token 计量，最多自动恢复一次；JSON 围栏、相邻数组括号错位只做词法层兼容，角色与长度校验仍生效。
- 用实际 DeepSeek API 完成 3600×、24 世界小时的无人干预验证：30 次请求、119 事件、28 条 AI 消息、4 位发言角色、6 个有 AI 内容的会话；用户消息 0。时间有序、活动无重叠、引用完整、重复运行幂等。
- 真实生成还覆盖一套包含两位原创角色与一个团体的世界草稿，以及一个团体和对应角色草稿。没有覆盖已有用户世界。

证据：[无人干预报告](LIVE-DEBUG-2026-10-22.json)、[整套创建草稿报告](CREATION-LIVE-DEBUG-2026-10-22.json)。这些实际调用消耗了用户配置接口的 Token；测试在受限的隔离浏览器/数据库内完成，报告不含密钥。真实世界没有被加速、回退或改写。

实时调试还发现并修复：导入 UUID 人物后组合阅读游标过长，导致导出校验失败。新私聊编号使用稳定哈希，并兼容旧阅读游标的较长 ID。

本轮生产构建及 PWA 离线刷新复验通过；浏览器专项确认：3600× 前台加速在断网时停止放大时间。
