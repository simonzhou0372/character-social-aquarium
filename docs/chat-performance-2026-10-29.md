# 聊天与调度增量优化验证（2026-10-29）

## 实现与边界

- 数据库 v17 增加会话/虚拟时间/ID、会话/虚拟时间/序号与回复目标索引。历史以稳定 ID 游标分页；默认 40 条、滑动窗口最多 160 条、虚拟缓冲 5 项，测量缓存随窗口清理。最多保留 30 个会话阅读锚点，不缓存其历史正文。
- 聊天列表只读取各会话最后一条消息和未读计数；已读只写实际可见消息，游标按 128 条分块推进。生成上下文最多查询 48 条并沿用原 18 条上下文；记忆整理沿用原 30 条内容，序号分配改为索引末项查询。
- 批处理由就绪负载、平均等待和倍率触发，持久化滞回状态；结合输入/输出预算、实际输出吞吐与失败率限制批次。保留权限与依赖检查、任务持久化、完成去重和已有背压，不新增真实 API 请求。
- 历史导航支持世界历法、未读、最早/最新、线下故事、重大事件和引用。线下标记只关联全部会话参与者均在场的场景；入口只保留元数据，完整对白按点击读取。
- 多选独立于 DOM，支持 Shift 范围和世界日期范围。专用 Canvas 按数据库批次生成 1440×2400 PNG，GIF 取静态帧；结果暂存本地 IndexedDB，当前预览与最多 8 张小尺寸缩略图有界。关闭清理临时结果，异常退出结果保留最多 24 小时并在下次导出清理。ZIP 按 32 MB 分包，ZIP 库按需加载。
- 默认演出阅读，复用已保存对白和原有播放控制；新增本地阅读进度与全局默认模式选择。

## 离线 Mock 对照

固定 8 个同权限、共享背景任务，输出内容逐项断言相同；没有推进超过 1 小时的模拟，没有真实 API 消耗。Token 数是 Mock 按文本估算，不是服务商账单，也不含真实缓存价格。

| 倍率  | 串行请求 | 自适应请求 | 串行估算 Token | 自适应估算 Token |
| ----- | -------: | ---------: | -------------: | ---------------: |
| 1×    |        8 |          2 |          14304 |             4260 |
| 1440× |        8 |          1 |          14304 |             2268 |

该样本刻意具备可共享背景；不同权限、因果依赖或无法节省输入的任务仍独立生成。不能据此推断所有世界的节省比例、真实模型质量或真实 tokens/s；模型输出吞吐仍可能是上限。

## 验证

- 本地 50,000 条记录：同时间不同 ID、前后分页、回溯插入、目标区间、实际已读与场景可见性。
- 上下文与 AI 社交动作回归、Mock 调度：25 项定向单元测试通过；另 2 项旧版本迁移与 1 项隐私隔离用例通过。
- 浏览器：桌面 1440×810、超宽屏 2560×1080、手机 390×844、横屏 844×390；50,000 条历史挂载约 11～14 个消息节点，断言少于 45；新增消息及切换会话返回时阅读锚点偏移小于 8 px，历史定位、PNG/ZIP 导出和演出恢复均有测试。
- 旧全量套件包含超过本轮一小时上限的离线模拟用例，早期启动后发现这一点并终止；没有将其计作完整回归通过，后续使用受限定向测试。
- 当前默认七日存档独立于聊天测试：浏览器测试屏蔽其自动安装入口，继续使用原五角色小世界，兼容新旧引导按钮文案。
- 构建包含 TypeScript 检查。原工程仍有主包体积及静态/动态混用的构建提示。

## 尚未覆盖的长期验证

没有进行真实模型账单/吞吐对照、数月连续运行或真实手机浏览器的长期堆内存观测；有界数据/节点/资源生命周期不等同于已测得某个堆内存节省百分比。跨角色公开信息传播的场景关联采用保守规则，不推断缺席群成员已知私人事件。系统分享依赖浏览器文件分享能力。
